Universal CSV Data Analyzer

**Input:** Any `.csv` file
**Processing:** Automatically detect columns, data types, missing values, relationships, and statistical patterns
**Output:** Interactive dashboard + charts + insights + downloadable report

### Recommended Features

1. **CSV Upload**

   * Drag & drop / browse CSV
   * Automatically detect delimiter and encoding
   * Preview first/last rows
   * Dataset size: rows × columns

2. **Automatic Data Profiling**

   * Numerical / categorical / datetime column detection
   * Missing values
   * Duplicate records
   * Unique values
   * Outliers
   * Min / Max / Mean / Median / Standard deviation
   * Data quality score

3. **Automatic Visualization**
   Based on the detected column types:

   * Bar chart
   * Line chart
   * Pie / donut chart
   * Histogram
   * Box plot
   * Scatter plot
   * Heatmap
   * Correlation matrix
   * Time-series analysis

4. **AI/Automatic Insights**
   For example:

   > "Sales increased by 23.4% during the final quarter."

   > "Column `Age` contains 4.2% missing values."

   > "`Income` and `PurchaseAmount` show a strong positive correlation."

   > "`ProductCategory` has the highest number of records."

5. **Natural-Language Analysis**

   User could type:

   > "Show me the top 10 products by revenue."

   > "Which month had the highest sales?"

   > "Find unusual values."

   > "Compare category A and category B."

   The system generates the appropriate analysis/chart automatically.

6. **Dashboard**

   Something like:


9. Outlier Engine
Use multiple approaches.
IQR
Q1 = series.quantile(0.25)
Q3 = series.quantile(0.75)

IQR = Q3 - Q1

lower = Q1 - 1.5 * IQR
upper = Q3 + 1.5 * IQR
Z-score
scipy.stats.zscore()
Isolation Forest
For multidimensional anomaly detection:

One important design decision
I would not put everything into one enormous main.py. Even though the backend is 100% Python, separating the analysis engines makes it much easier to maintain and extend.
The result would essentially be a Python-based automated data scientist:
CSV → ingestion → profiling → cleaning → EDA → statistics → visualization → correlations → outliers → time series → statistical tests → ML → insights → PDF/Excel report.
And because the analysis engine is dataset-independent, the same backend can analyze a supermarket dataset today and a student, finance, HR, healthcare, or sales dataset tomorrow.
